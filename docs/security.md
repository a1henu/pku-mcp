# 安全与隐私

pku-mcp 完全在你自己的电脑上运行，直接访问北大的网站，中间不经过任何第三方服务器。下面说明它存了什么、存在哪、能做什么、不能做什么。

## 存了什么，存在哪

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 学号、隐藏的课程等设置 | `~/.pku-mcp/config.json` | |
| IAAA 密码、手机令牌密钥 | `~/.pku-mcp/secrets.json` | 明文 JSON，文件权限 0600（只有你的系统账户能读） |
| 登录会话 Cookie | `~/.pku-mcp/sessions/` | 用来免重复登录 |
| 最近一次读取的数据 | `~/.pku-mcp/cache/` | 10 分钟内复用 |
| 下载的资料 | `~/PKU/` | 可以用 `dest` 参数或 `PKU_FILES_DIR` 改位置 |

为了能在 macOS、Windows、Linux 上都开箱即用，密码和令牌密钥没有放进系统钥匙串，而是放在上面这个只有你能读的文件里。这意味着：

- **能登录你电脑账户的人，就能读到你的北大密码和令牌密钥。** 请给电脑设开机密码，不要和别人共用系统账户。
- 手机令牌是「第二道锁」，把它的密钥放在电脑上，这道锁就和电脑绑在了一起。介意的话可以不绑定令牌，只用教学网相关功能（作业、公告、资料不需要令牌）。
- 不要把 `~/.pku-mcp` 文件夹同步到网盘、发给别人，或放进 Git 仓库。
- 不用了就运行 `pku-mcp forget`，它会删除密码、令牌密钥和登录会话。

## AI 能看到什么

- 任何工具的输入和输出里都**不会**出现你的密码、令牌密钥或 Cookie。账号只在本机配置网页里填写，那个网页只监听 `127.0.0.1`，地址里带一次性的随机令牌，闲置 15 分钟自动关闭。
- `otp_code` 工具会把**当前**的 6 位动态口令交给 AI，方便它帮你登录其他北大网页。口令 30 秒左右就失效。
- 作业、公告、成绩等数据会进入 AI 对话，和你自己把这些内容复制给 AI 是一样的。介意的话就不要问相关问题。

## 它能做什么、不能做什么

- **只读。** 查询和下载，不会提交作业、选退课、修改教学网上的任何内容。
- **只访问北大的网站**（`*.pku.edu.cn`），代码里拦截了其他域名。
- **下载不覆盖。** 已有同名文件时另起名字，内容相同就复用，从不删除你的文件。
- **防止锁号。** 登录失败后自动暂停 5 分钟（北大提示「尝试次数过多」时暂停 30 分钟）再重试，避免触发北大统一认证的锁定。
- 网页正文被当作普通数据，AI 不应执行其中的「指令」。

## 发现问题

请在 GitHub 提 issue，不要在 issue 里贴学号、密码、截图或 Cookie。
