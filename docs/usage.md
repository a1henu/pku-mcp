# 功能与用法

装好以后，直接用中文跟你的 AI 助手说想做什么就行，它会自己挑合适的工具。下面是能做的事和背后对应的工具，方便你（或你的 Agent）查。

## 开学：一键整理整个学期

> 「开学了，帮我把这学期的课程资料整理好。」

Agent 会调用 `semester_sync`，把每门课的课件、作业附件、公告附件下载到电脑上，按课程分好文件夹，并生成两类说明文件：

```
~/PKU/26-27学年第1学期/
├── README.md                 ← 学期总览：每门课的上课时间地点、考试、未交作业
├── 计算机网络/
│   ├── 课程信息.md            ← 这门课的上课安排、作业截止和状态、公告、资料索引
│   ├── 资料/教学内容/第一章/…
│   ├── 作业/lab2发布/…
│   └── 公告/2026-09-06 课程微信群/…
└── 自然语言处理/
    └── …
```

- 想放到别处，就告诉 Agent 文件夹位置（参数 `dest`）。
- 可以随时再整理一次：已经下载过的文件不会重复下载，也**不会覆盖或删除**你放进去的任何东西；只有 `README.md` 和 `课程信息.md` 会刷新。
- 默认跳过 100 MB 以上的文件（多是录像），会列出来，需要时再让 Agent 单独下载。
- 退课或不想管的课，先让 Agent 用 `course_hide` 标记，整理和作业列表就会跳过它。

## 平时：作业、公告、课表、成绩

| 你可以说 | 用到的工具 |
| --- | --- |
| 「这周还有哪些作业没交？」 | `assignment_list`：截止时间、是否已交、提交时间、成绩、作业要求和附件 |
| 「最近有什么新公告？」 | `announcement_list` |
| 「明天几点在哪上课？」「离散数学什么时候考试？」 | `schedule_list`：节次和钟点、教室、老师、单双周、考试安排 |
| 「NLP 的课件里有没有讲 Transformer？」 | `content_list`：一门课的全部内容，可按关键词找 |
| 「把这个附件下载下来」 | `attachment_download`，默认存到 `~/PKU/下载` |
| 「我上学期 GPA 多少？」 | `grade_list` |
| 「我要登录选课网，给我一个令牌口令」 | `otp_code`：当前手机令牌口令，30 秒内有效 |

## 写作业

> 「帮我做计算机网络的 lab2。」

Agent 会找到作业要求和截止时间，把附件同步到 `课程/作业/作业名/` 文件夹，然后在这个文件夹里和你一起写。**它不会替你在教学网上提交**，最后会提醒你提交方式和截止时间。

## 预设流程

在支持 MCP prompts 的应用里（例如 Claude Code 的斜杠命令），可以直接选：

| 名称 | 做什么 |
| --- | --- |
| `init_semester` 开学初始化 | 检查登录 → 确认课程 → 整理全部资料 → 给出学期概览 |
| `weekly_plan` 本周要做什么 | 未交作业 + 最近公告 + 今明两天的课，排成待办清单 |
| `homework` 帮我写作业 | 找作业 → 下载附件 → 一起完成（不提交） |

## 账号相关

| 情况 | 怎么办 |
| --- | --- |
| 第一次用、改了密码、换了手机令牌 | 跟 Agent 说「打开 pku-mcp 配置页」（`auth_setup`），或在终端运行 `pku-mcp setup` |
| 想看配置状态 | `pku-mcp status`，或让 Agent 调用 `auth_status` |
| 想彻底删除保存的账号 | `pku-mcp forget` |

## 需要知道的限制

- **数据有 10 分钟缓存。** 想要最新结果就说「刷新一下」（`refresh=true`）。读取失败时会返回上次成功的数据，并标注 `stale`。
- **不推算教学周。** 课表会写明单周、双周和周次范围，今天是第几周需要你确认一次。
- **只在公告里布置的任务**不会出现在作业列表里，需要再看公告。
- 课程回放、选课、校园卡、图书馆暂未接入。

## 命令行（可选）

不用 AI 也能直接用：

```
pku-mcp setup            打开配置网页（--terminal 改在终端输入）
pku-mcp sync             整理本学期资料（--dest 指定位置）
pku-mcp check            用真实账号检查登录和各项数据
pku-mcp status           查看配置和 MCP 启动命令
pku-mcp otp code         显示当前手机令牌口令
pku-mcp otp bind --qr 图片 | --clipboard | --stdin    保存令牌密钥
pku-mcp logout | forget  清除登录会话 / 删除全部本机账号数据
```

环境变量：`PKU_MCP_HOME` 改账号数据位置（默认 `~/.pku-mcp`），`PKU_FILES_DIR` 改资料和下载位置（默认 `~/PKU`）。
